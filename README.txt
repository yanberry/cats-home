快速启动说明

文件列表：
- index.html    -- 入口页面
- category.html -- 分类页面
- styles.css    -- 样式文件
- app.js        -- 前端逻辑（使用 localStorage 保存帖子与日历事件）
- category.js   -- 分类页面逻辑

使用步骤：
1. 在文件管理器中双击 index.html 或在浏览器中打开它（无需服务器，直接本地打开可用）。
2. 日历区在页面顶部，支持选择日期、添加事件、编辑事件和删除事件。
3. 微博发布区在日历下方，输入微博内容后点击“发布”即可。
4. 页面顶部有“学习/生活/规划/资源/项目”分类横条，点击后会跳转到对应的分类新页面。
5. 新增“规划进度看板”，支持目标量化进度展示，微博与日历事件均可关联目标。

后续建议：
- 若要上线：将文件部署到静态托管（如 GitHub Pages、Netlify），或添加后端（Node/Express + 数据库）以实现用户、登录和持久化。
- 可以改进：增加事件提醒、图片、文件上传、评论系统、搜索和过滤等功能。
